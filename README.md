# Nook

A cozy 3D library you sit inside. Drag to look around, tap a tag to use something:

- **Your table**: a focus timer. Each finished session becomes a new book on the shelves.
- **The stacks** and **Card catalog**: your study history, by subject and by day.
- **Window seat**: a reading log.
- **Mochi**: the library cat. Pet her or wake her up.
- **Fireside**: soft ambient sound (fire, rain, a little music).

The light follows your real time of day (morning, day, golden hour, night), and you can switch it by hand.

## Run it

```
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

`npm run build` makes a static site in `dist/` that you can host anywhere.

Built with three.js and Vite. Everything runs in the browser.
